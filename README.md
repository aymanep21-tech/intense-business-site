# موقع انتنس للدعاية والإعلان | INTENSE

موقع تعريفي عربي ثابت، جاهز للنشر على GitHub Pages دون أدوات بناء أو مكتبات خارجية.

## الملفات
- `index.html` الصفحة الرئيسية.
- `privacy.html` سياسة الخصوصية.
- `favicon.svg` أيقونة الموقع.

## النشر
1. أنشئ مستودعًا عامًا باسم `intense-business-site`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع (يجب أن يكون `index.html` في المستوى الرئيسي، لا داخل مجلد فرعي).
3. افتح **Settings → Pages**.
4. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، واحفظ.
5. انتظر اكتمال النشر، ثم افتح الرابط الذي سيظهر في صفحة Pages.

## قبل استخدام الرابط في Meta
راجع الاسم القانوني والعنوان ورقم السجل والتواريخ حرفيًا مع أصل المستند الرسمي. لا تضف هاتفًا أو بريدًا غير مملوك للنشاط. نشر الموقع لا يضمن قبول التحقق من Meta.
